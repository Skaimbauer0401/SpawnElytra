# Spawn Elytra – Logo

Pixel-art elytra on a dark tile (variant "Violett"). Own drawing on a 16 × 16 grid, no game textures.

| File | Use |
|---|---|
| `spawn-elytra-logo.svg` | master, with tile |
| `spawn-elytra-logo-transparent.svg` | master, no tile |
| `spawn-elytra-logo-{2048,1024,512,256,128}.png` | icon (Modrinth, GitHub, avatars) |
| `spawn-elytra-logo-transparent-{2048,512}.png` | on own backgrounds |
| `favicon.ico` | 16–256 px |

Colours: outline `#1d1830`, light `#c9b8ff`, mid `#8f74e8`, shadow `#5a43b0`, tile `#120f1f`.
Scale only by whole multiples of 16 px so the pixels stay sharp.
